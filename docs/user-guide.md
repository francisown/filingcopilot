# 使用指南

FilingCopilot 把行情、公司披露、财务计算和研究记录放在同一工作台中。
第一次使用可以从内置的 Apple 年报开始，不需要模型密钥。

## 安装与配置

需要 Python 3.10 或以上。Windows PowerShell 在项目根目录执行：

```powershell
.\setup.ps1 -Language zh
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item .env.example .env
}
$env:FC_EMBEDDING_MODE = "off"
.\start.ps1 -Port 8159
```

打开 <http://127.0.0.1:8159/>。服务运行期间保留终端窗口，按 `Ctrl+C` 停止。
macOS/Linux 的安装命令及解释器选择见[安装说明](installation.md)。

配置写在本地 `.env` 中。已有配置应保留，密钥不要加入 Git。

| 配置项 | 用途 |
|---|---|
| `FC_SEC_USER_AGENT` | 下载 SEC 文件所需的联系人和邮箱。 |
| `FC_API_BASE` / `FC_API_KEY` | 支持工具调用的 OpenAI 兼容模型接口及密钥。 |
| `FC_MODEL` / `FC_REVIEW_MODEL` | 研究模型和复核模型；应使用不同模型进行独立复核。 |
| `FC_EXTRA_HEADERS` / `FC_SESSION_ID` | 供应商要求的额外请求头或会话标识。额外请求头使用 JSON 对象。 |
| `FC_EMBEDDING_MODE` | `off` 使用关键词检索；`local` 启用可选的本地向量检索。 |
| `FC_HOME` | 数据库、缓存及研究记录目录，默认 `.filingcopilot`。 |
| `FC_DOMAIN_CONFIG` | 可选的公司、指标及来源注册表文件。 |
| `FC_TWELVE_DATA_API_KEY` | 可选的日线行情补充来源。 |

本地向量检索需要安装 `.[semantic]`，首次使用可能下载模型权重。
研究模型会收到本次问题及相关证据，调用费用由配置的供应商计收。
仅查看内置数据、执行支持的财务计算或复核已导出的研究包时，无需模型调用。

## 完成第一次查询

1. 选择 Apple / AAPL，将知悉日期设为 `2026-10-08`。
2. 选择“无模型研究”，输入“苹果 FY2025 营收与净利润”。
3. 展开引用，查看申报文件、期间、币种和原始金额。
4. 导出研究包，按下文命令离线复核。

网页中的金额通常显示至多两位小数；计算与导出保留原始精度。
问题可以用中文或英文提出，新研究的输出语言由本次选择决定。

英文回答的结果标题旁有“中文”按钮。点击后只在右侧打开当前回答的中文对照，
不会切换到全局中文界面、替换英文原文或重置阅读位置；源证据和数字保持原样。
这是按需机器翻译，需要配置模型；翻译失败不会改动或删除英文回答。

配置模型后，可切换到“Agent 研究”询问变化原因或研究经营风险。
明确的年度金额、同比和利润率通常可以直接查询与计算；解释性问题需要检索原文并复核表述。

## 股票与公司资料

### 搜索和行情

输入公司名称或代码后，确认具体上市证券。相近名称、不同市场和股份类别可能对应不同标的。
行情查询与财报准备分别执行，查看价格图无需等待年报下载。

走势图支持一年、五年和全部历史区间，可切换线性或对数刻度。
查看价格时同时留意币种、数据时间、供应商和复权方式。
供应商当前返回的复权序列可能包含后续公司行动的调整，不能直接当作历史时点保存的回测数据。

### 公司研究页

页面分为九个资料模块：商业模式、经营变化、现金流与资本投入、负债与流动性、风险、
近期事件、估值、上市股份与币种、审计报告原文。
支持的公司会自动准备财报；已取得的数字可以先显示，索引和其他来源继续处理。

每个模块可单独生成文字总结，结论附引用、期间和待补信息。
“完整公司研究”另按商业模式、增长、现金流、竞争、风险、估值六个主题组织报告。
模块写作规则见[模块总结规范](company-research-summary-format.md)。

近期事件区收录支持的官方披露及已接入的外部更新。
事件日期、文件公开日期和系统取得日期分别记录；媒体归因不等同于公司披露。
模型摘要保留原文链接，未取得的公告不会补写成已知事实。

### 公司对比

选择公司后，可比较共同历史区间的价格及可取得的财务指标，也可加入 SPY 或 QQQ 基准。
缺失年份保留空缺，不以零补齐。财年截止日、币种和上市股份不同的公司，需要先检查比较口径。
有行情并不意味着同一证券的财报和估值数据也已覆盖。

## 财务口径

### 年度、季度与 TTM

财报封面的年度与其中比较列的年度可能不同。引用同时保留申报文件和实际财务期间，
跨年度计算按事实期间配对。

季度资料区区分单季度、年初至今累计（YTD）、全年和时点数据。
可取得的三表行按申报版本展示；缺少独立季度数据时，不统一推算第四季度。

TTM 流量采用匹配期间的“上年全年 + 本期累计 − 上年同期累计”。
利润率从对应利润和收入重新计算，不能把百分比相加。
资产负债表时点余额、EPS 和普通现金流量的计算口径不同，不能一律按流量累加。

### 现金流与估值

自由现金流计算保留经营现金流和现金资本开支的原始输入，区分购置支出与扣除处置收入后的净额。
计算要求公司、币种、来源和期间匹配。

现金流敏感性工具使用来源匹配的年度数据和用户假设，单独导出计算记录。
其中“经营现金流减现金 PP&E 购置支出”是现金流代理量，不是企业价值或股票目标价。

年度市盈率和供应商 TTM 市盈率分别展示。历史知悉日期不能使用今天取得的供应商 TTM EPS。
普通股与 ADS 的价格/EPS 配对还需要股份比例、币种和对应日期的汇率。

## 日期、执行与结果状态

“知悉日期”限制当时可用的公开资料，财务期间说明数字所属的经营区间，两者不可互换。
来源范围和日期随研究包保存，后续刷新资料不会改写已有研究。

研究过程中可以查看步骤、取得的证据和剩余预算，也可取消任务。
模型调用、工具调用、输出长度和总时限由配置约束；供应商故障可能触发重试或模型切换。
切换后会记录实际使用的模型，复核不独立时会在结果中说明。

| 状态 | 含义 |
|---|---|
| `answered` | 通过当前检查，未记录未解决的回答缺口。 |
| `partial` | 已交付可核验内容，但仍缺少部分证据、解释或执行步骤。 |
| `abstained` | 没有可交付的受支持内容。 |

这些状态用于描述流程结果，不是人工正确率。遇到 `partial`，先阅读具体缺口，
再决定缩小问题、补充来源或重新运行。预算耗尽不会把未完成内容算作完整回答。

## CLI 与 API

以下命令使用 Windows 环境；macOS/Linux 将解释器路径换成 `.venv/bin/python`。

```powershell
.\.venv\Scripts\python.exe -m filingcopilot ask "苹果 FY2025 营收与净利润" --ticker AAPL --mode reference --as-of 2026-10-08 --language zh
.\.venv\Scripts\python.exe -m filingcopilot catalog
.\.venv\Scripts\python.exe -m filingcopilot versions AAPL revenue 2024 --as-of 2026-10-08
```

使用 `python -m filingcopilot --help` 查看命令。全局 `--home` 放在子命令之前。
启动服务后，可在 <http://127.0.0.1:8159/docs> 查看 API 的参数和响应结构。

| 接口 | 用途 |
|---|---|
| `/api/research` | 提交研究请求。 |
| `/api/financial/trend` | 多年财务趋势。 |
| `/api/comparison` | 公司及行情比较。 |
| `/api/catalog` | 当前数据覆盖。 |
| `/api/runs` | 已保存的研究记录。 |
| `/api/evidence/{id}` | 证据详情。 |
| `/api/health` | 服务状态。 |

MCP 支持标准输入输出及 Streamable HTTP，接入配置与 30 个工具的列表见
[MCP 说明](mcp-tools.md)。默认 Web 服务绑定本机地址；公开部署前需要另外配置访问控制。

## 研究包与离线复核

研究包保存回答、证据、公式、配置和来源摘要，可从网页导出，也可以直接通过命令生成：

```powershell
.\.venv\Scripts\python.exe -m filingcopilot ask "苹果 FY2025 营收与净利润" --ticker AAPL --mode reference --as-of 2026-10-08 --language zh --package --output artifacts/package.json
.\.venv\Scripts\python.exe -m filingcopilot verify-package artifacts/package.json --output artifacts/audit.json
```

验证器离线运行，不调用模型。提供可信的原件缓存后，还能对照原始字节：

```powershell
.\.venv\Scripts\python.exe -m filingcopilot verify-package artifacts/package.json --source-cache .filingcopilot/sec-cache
```

没有原件时，对应检查记为缺失。`consistent` 只说明已执行的检查一致，不代表重新完成了叙述评审。
独立安装方法、可用检查和篡改示例见[独立验证器](independent-verifier.md)。

## 排查常见问题

| 情况 | 检查方法 |
|---|---|
| 安装失败 | 确认 Python 版本及虚拟环境；镜像缺少构建依赖时按安装说明切换包源。 |
| 无法取得 SEC 文件 | 检查联系人配置、网络和来源返回的错误；已有缓存可继续用于其覆盖范围内的查询。 |
| 模型请求被拒绝 | 检查接口地址、模型名称、工具调用能力和供应商要求的请求头。 |
| 原件与缓存摘要不符 | 保留失败记录，核对来源并重新取得资料；不要关闭完整性检查。 |
| 图表为空或财务年份缺失 | 查看数据覆盖与所选日期，区分行情、年度、季度和原文来源。 |
| 研究只有数字，没有原因解释 | 查看解释部分的来源或预算缺口；数字完成不等于因果分析完成。 |

开发与测试见[贡献指南](../CONTRIBUTING.md)和[测试说明](test-profiles.md)，
评测结果及范围见[评测说明](evaluation.md)。
