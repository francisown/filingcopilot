# Generated evidence

Result JSON, traces, screenshots and local validation receipts are generated
artifacts. They are gitignored and are not part of the public source snapshot,
except for the latest live-evaluation record linked from
[Evaluation](../docs/evaluation.md).

The public repository keeps methodology and current limitations in:

- [Evaluation limits](../docs/evaluation.md)
- [Reproducing the evaluation](../docs/reproducing-evaluation.md)
- [FinanceBench results](../docs/financebench-scoped-2026-10-23.md)

Do not treat local artifacts as a current production accuracy claim.
